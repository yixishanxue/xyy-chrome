# Xyy 定制版 Chrome++ (Xyy's Chrome++ Gesture Edition)

本项目基于开源项目 [Chrome++ Next](https://github.com/Bush2021/chrome_plus) 修改并重新编译。

**Xyy** 在原版强大的增强功能基础上，深度定制了底层鼠标手势功能，打造了一个极低延迟、全场景覆盖的增强版 Chrome 注入补丁。

---

## 🚀 突破限制：无视所有页面的底层手势

市面上的鼠标手势扩展（如 crxMouse、Gesturefy 等）受限于 Chrome 的安全沙箱机制，在 `chrome://` 系统页面（如设置、新标签页）、Chrome 应用商店以及部分自家域名页面中是**完全失效**的。

**Xyy 定制版手势**直接在 Windows 底层 DLL 层面拦截鼠标事件，完全脱离了网页环境的限制。这意味着：

* ✅ **全场景顺滑操作**：无论在普通网页、新标签页、设置页，还是 Chrome 应用商店，手势统统生效。
* ✅ **零延迟响应**：无需等待网页渲染，直接由底层触发，顺滑无比。
* ✅ **蓝色轨迹可视化**：按住右键滑动时，屏幕实时绘制蓝色轨迹，松开即消失。

## ✨ 核心手势指令

* ⬅️ **左滑**：恢复最近关闭的标签页。
* ➡️ **右滑**：关闭当前标签页。
* ⬆️ **上滑**：滚动到页面顶部。
* ⬇️ **下滑**：滚动到页面底部。

*(注：所有指令均不受网页焦点限制，随处可用。)*

## 🍃 纯绿色便携特性

* **无感注入，纯净体验**：仅需将 `version.dll` 与 `chrome++.ini` 放入 Chrome 程序目录，无需安装，不写注册表。
* **数据本地化**：保留 Chrome++ 的便携特性，浏览器数据默认生成在程序同级目录，完全绿色无痕。
* **全面保留原版功能**：双击关闭标签、右键关闭标签、滚轮切换标签等原版功能全部保留，不冲突。

---

## 🛠️ 安装与配置

1. **准备**：请使用 Chrome 官方离线压缩包解压出的目录（避免被浏览器自动更新覆盖补丁）。
2. **部署**：将本仓库提供的 `version.dll` 和 `chrome++.ini` 复制到与 `chrome.exe` 同级的目录中。
3. **启动**：双击运行 `chrome.exe` 即可生效。

### 配置调整 (`chrome++.ini`)
若需修改手势，可直接用记事本编辑：
```ini
[tabs]
gesture_enable=1        ; 1为开启手势，0为关闭
gesture_min_distance=30 ; 触发手势的最小像素距离
